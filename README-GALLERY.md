# Cara mengganti gambar gallery

Masukkan gambar ke folder:

`public/images/`

Gunakan nama berikut:

- media-01.jpg
- media-02.jpg
- media-03.jpg
- media-04.jpg
- media-05.jpg
- media-06.jpg
- media-07.jpg
- media-08.jpg
- media-09.jpg
- media-10.jpg

Bisa juga memakai PNG dengan nama yang sama (`media-01.png`, dst.).

Jika belum ada gambar JPG/PNG, halaman otomatis memakai placeholder SVG `media-01.svg` sampai `media-10.svg` sehingga gallery tetap tampil.

Untuk mengubah gambar utama, ganti file:

`public/stitch/mockup-b1edc6c7a8404b5295c324184c2882a9.png`
